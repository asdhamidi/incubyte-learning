# Day 7 Exercise: Reviewing a Data Change

A code review exercise. `exercise-1/pr-to-review.md` is a teammate's pull request (a revenue-by-currency summary with CI passing), and `exercise-1/review.md` is the review of it.

## Files

- `exercise-1/pr-to-review.md`: the PR to review, with its description, files changed and diff
- `exercise-1/review.md`: the review, with a verdict, blocking issues, suggestions and nits

The CI setup from the same day lives at the repo root (`ci.py`, `.github/workflows/ci.yml`, `requirements.txt`). Run it with `python ci.py`.
